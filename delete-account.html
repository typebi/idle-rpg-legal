[게임명] 계정 및 데이터 삭제 요청

[게임명]([운영자명])의 계정과 게임 데이터 삭제를 요청하는 방법을 안내합니다.

1. 게임 안에서 바로 삭제하기

게임을 설치해 두셨다면 설정 → 계정 삭제에서 바로 지울 수 있습니다. 확인을 한 번 더 거친 뒤 즉시 삭제되며 되돌릴 수 없습니다.

2. 앱을 이미 지운 경우

[문의 이메일] 로 아래 내용을 보내 주세요. 받은 날부터 10일 안에 처리하고 결과를 회신합니다.

  • 제목: 계정 삭제 요청
  • 설치 ID(게임 설정 → 계정에 표시, 복사 버튼이 있습니다) — 모르시면 결제 주문 번호(Google Play 영수증 메일의 GPA.로 시작하는 번호)
  • 연동한 Google Play 게임즈 계정이 있다면 그 사실

이 게임은 이름·이메일을 받지 않으므로 위 번호로만 계정을 찾을 수 있습니다. 둘 다 없으면 계정을 특정할 수 없어 삭제할 수 없습니다.

3. 삭제되는 정보

  • 계정(플레이어 ID·설치 ID·닉네임)과 게임 데이터, 게임 데이터 백업
  • 광고 보상 기록, 쿠폰 사용 기록, 우편함, 부정 이용 탐지 기록, 외부 계정 연동 정보
  • 설치 ID 로 연결된 게임 이용 기록(통계) — 개인을 알아볼 수 없는 합계 통계만 남습니다
  • 남아 있던 게임 재화(유료 다이아 포함)와 아이템도 함께 사라집니다(이용약관)

4. 삭제 후에도 보관되는 정보

관계 법령에 따라 다음 기록은 계정을 삭제해도 정해진 기간 동안 따로 보관한 뒤 파기합니다.
